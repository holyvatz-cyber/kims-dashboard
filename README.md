# KIMS přehled · Knauf Insulation

Dashboard pro exporty z Knauf Integrated Management System (úrazy a incidenty, neshody a audity, řízení změn).

**Aplikace neobsahuje žádná firemní data.** Po otevření nahrajte exporty Accidents, NCRs a MOCs ve formátu .xlsx. Soubory se zpracují jen ve vašem prohlížeči a nikam se neodesílají.

Otevřít: https://holyvatz-cyber.github.io/kims-dashboard/
